# 2️⃣ Lista de Eventos

**Nível:** Iniciante 🟢 | **Diretório:** `/ListaDeEventos`

App de eventos com listagem, filtros e detalhe em SwiftUI. O foco é dominar composição de listas e navegação com Swift.

## 🎯 Objetivo
Construir uma lista de eventos com cards, busca local e tela de detalhe em SwiftUI para treinar modelagem e apresentação.

## 🛠️ Tecnologias e Práticas
- `Swift`
- `SwiftUI`
- `List` e `ForEach`
- `Navegação lista/detalhe`
- `Modelos Codable`
- `Filtro e ordenação`
- `Componentização de células`

## ✅ Requisitos para entrega
- Renderizar lista de eventos com título, data e local.
- Permitir busca por nome e filtro por categoria.
- Exibir tela de detalhe com descrição completa.
- Manter estado de filtros entre navegações.
