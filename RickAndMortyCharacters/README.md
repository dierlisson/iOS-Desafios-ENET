# 4️⃣ Rick & Morty Characters

**Nível:** Intermediário 🟡 | **Diretório:** `/RickAndMortyCharacters`

Integração com API REST em Swift usando async/await e exibição de personagens em SwiftUI.

## 🎯 Objetivo
Consumir API pública em Swift, listar personagens paginados e exibir detalhes em SwiftUI com feedback visual para erros e loading.

## 🛠️ Tecnologias e Práticas
- `Swift`
- `SwiftUI`
- `URLSession`
- `Async/Await`
- `Decoding com Codable`
- `Tratamento de erro`
- `AsyncImage e placeholders`

## ✅ Requisitos para entrega
- Tela de lista com estados de loading e erro.
- Busca por personagem com debounce simples.
- Tela de detalhe com imagem e atributos principais.
- Tratamento de falhas de rede e retry.
