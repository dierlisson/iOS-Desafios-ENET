# 6️⃣ Pokédex

**Nível:** Avançado 🔴 | **Diretório:** `/Pokedex`

Projeto final em SwiftUI com API, paginação e foco em qualidade de software com testes automatizados.

## 🎯 Objetivo
Entregar uma Pokédex em SwiftUI com busca, detalhe e paginação, aplicando testes unitários e organização de código.

## 🛠️ Tecnologias e Práticas
- `Swift`
- `SwiftUI`
- `XCTest`
- `Paginação incremental`
- `Mocks de repositório`
- `Validação de regras`
- `Boas práticas de código`

## ✅ Requisitos para entrega
- Listar pokémons com carregamento paginado.
- Busca por nome e filtro por tipo.
- Tela de detalhe com atributos e imagem.
- Suite mínima de testes para casos críticos.
